📝 Bootstrap Form Page

A responsive billing and payment form page built using Bootstrap 5.
This project demonstrates Bootstrap form components, grid system, and built-in validation styling.

🚀 Project Overview

This project is a fully responsive form page that simulates a billing and checkout process. It includes:

Billing address form

Country and state selection

Payment method selection

Credit card information fields

Form validation using Bootstrap validation classes

The layout is built using Bootstrap’s grid system and form utilities.

✨ Features

Responsive layout using Bootstrap grid (row, col-md-*)

Styled form components (form-control, form-select, input-group)

Bootstrap validation styling (needs-validation, invalid-feedback)

Radio buttons and checkboxes

Payment section with card details

Clean and structured HTML

🛠 Technologies Used

HTML5

CSS3

Bootstrap 5.3

Bootstrap Bundle JS
